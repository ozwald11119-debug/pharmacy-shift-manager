# 薬局16店舗シフト管理（プロトタイプ）

`index.html` をブラウザで開くと動作します。GitHub Pagesにも配置できます。

## 現在の機能
- 16店舗切替（うち13店舗は仮名）
- 月別シフト、スタッフ追加
- 日別の開始・終了時刻、休憩分入力
- 実働時間の合計表示、CSV出力

## 重要：本番利用不可
現在は `localStorage` に端末単位で保存するデモです。**店舗間同期・ログイン・アクセス制御・バックアップは未実装**です。実名や実際の勤務情報を登録しないでください。

## 本番化の設計
GitHub Pages（フロントエンド）+ Supabase Auth / PostgreSQL / RLS（認証、共有DB、店舗別権限）。スタッフIDを安定したUUIDで管理し、勤務枠はスタッフID・日付をキーにします。勤務変更の競合検出、編集履歴、管理者権限、バックアップを追加してから運用します。公開リポジトリに実データや秘密鍵を置かないでください。
